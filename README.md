# Apple Shortcut Workspace

This repository provides templates for generating iOS Shortcuts programmatically using:

- [CherriLang](https://github.com/electrikmilk/cherri)
- [Jellycuts (Open-Jelly)](https://github.com/OpenJelly/Open-Jellycore)

## ⚠️ Requirements

- Linux system
- Docker and Docker Compose installed and preconfigured
- Familiarity with Docker and Compose usage (this repo assumes you know the basics)

## 🔀 Branches

- [**`cherrilang`**](https://github.com/CKATEPTb/apple-shortcuts-workspace/tree/cherrilang) – contains a `.cherri` template and Docker-based build & sign flow
- [**`jellycuts`**](https://github.com/CKATEPTb/apple-shortcuts-workspace/tree/jellycuts) – contains a `.jelly`  template and Docker-based build & sign flow
- [**`readme`**](https://github.com/CKATEPTb/apple-shortcuts-workspace/tree/readme) – documentation and repository overview (you're here)

## 💡 Why Use This?

- Automate Apple Shortcut generation in Linux environments
- Integrate into CI/CD pipelines
- Maintain Shortcut source files in version control
